# Episode 8 (structured) · Go-to-Market Strategy & Recording Data

A 4 min 23 s explainer that follows the GTM workflow from the Marketing Strategy Framework lesson, one framework per step: **5Cs → segmentation → targeting → positioning → 4Ps → AIDAS journey → soft launch → ground-up budget → recording data (UTM, five-tab sheet) → measure and decide.** It uses real store facts (Episode 7 audit), cited research and course benchmarks. Example figures are tagged EXAMPLE on screen.

- `docs/storyboard.md`: scene-by-scene storyboard and narration
- `src/data.ts`: every fact, number and source shown (edit, then re-render)
- `src/scenes/Structured.tsx`: the scenes
- `out/aalayam-episode-8-gtm-structured.mp4`: the video
- `deliverables/`: 12 stills

The simpler 2-minute version is in `../episode-8-gtm/`; the full written plan is in `../marketing-plan/`. To render: `npm install`, `python scripts/build_audio.py` (the audio mix isn't committed), then `npx remotion render Episode8Structured out/aalayam-episode-8-gtm-structured.mp4`.
