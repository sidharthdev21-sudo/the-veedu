# Episode 7 · The short version

A simpler, 2-minute cut of Episode 7 for a general audience: one idea per screen, plain language, a few real numbers. It uses the same real data as the full episode (the live store's public catalogue, read 28 Nov 2026). See `../episode-7/` for the detailed version, report and data model.

Scenes: what we did → the store today (13 products, ₹1,000–1,700) → what's working (honest prices, WhatsApp size help) → what to fix (sizes 2 of 9, measurements 1 of 13, results not recorded) → a 3-question product rule → the next 90 days.

Render: `npm install`, `python scripts/build_audio.py` (rebuilds the audio mix, which is not committed because it is too large), then `npx remotion render Episode7Simple out/aalayam-episode-7-simple.mp4`.
